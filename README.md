# InterfazTelecom

Sitio web de Interfaz Redes y Telecomunicaciones. El proyecto vive en [`interfaz-redes-demo/`](interfaz-redes-demo/README.md).

```bash
cd interfaz-redes-demo
npm install
npm run dev        # abre la dirección que muestre Vite, p. ej. http://localhost:5173/
```

Instrucciones completas (producción, pruebas y dónde modificar servicios, fotografías y contacto) en
[`interfaz-redes-demo/README.md`](interfaz-redes-demo/README.md).

`interfaz-redes-web.zip` es el respaldo del proyecto original; la etiqueta git `respaldo-original` marca el mismo estado.
